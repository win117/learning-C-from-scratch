# learning-C-from-scratch
This repository documents my personal journey learning the C programming language. All exercises are organized by topic and are part of a self-paced course I’m following to strengthen my programming skills


## 📚 Topics Covered

| Folder | Topic |
|--------|-------|
| `01_variables_and_operators` | Variable declaration, arithmetic and logical operators |
| `02_control_structures` | `if`, `else`, `for`, `while`, `do-while` loops |
| `03_functions` | Function definitions, parameters, return values |
| `04_arrays_and_pointers` | One-dimensional arrays, basic pointers, memory access |
| `05_structures` | `struct` data types, creating and using custom types |

## 🎯 Objective

To build a solid foundation in C programming that will later support the development of firmware and embedded AI projects, including work on **ANIUET**, an educational AI kit I’m co-developing.

## 🛠 Tools Used

- C compiler (`gcc`)
- Text editor (e.g. VS Code, Sublime Text)
- Linux terminal 

## 🚀 Notes

All programs in this repository are created for learning purposes. The code will progressively increase in complexity as I gain confidence and approach real-world applications.

Feel free to explore, suggest improvements, or follow along.
